# RecipeNest - Frontend 🍳

This is the React-based frontend for the RecipeNest application, built with Vite and Tailwind CSS.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14+ recommended)
- npm or yarn

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack
- **React 19**
- **Vite** (Build tool)
- **Tailwind CSS** (Styling)
- **Lucide React** (Icons)
- **React Router DOM** (Navigation)
- **Recharts** (Analytics visualizations)
- **Axios** (API requests)
- **React Hot Toast** (Notifications)

## 📁 Key Directories
- `src/components`: Reusable UI components.
- `src/pages`: Main view components for Admin, Chef, and User portals.
- `src/assets`: Images and global styles.

## 📜 Available Scripts
- `npm run dev`: Runs the app in development mode.
- `npm run build`: Builds the app for production.
- `npm run lint`: Runs ESLint to find and fix problems.
- `npm run preview`: Previews the production build locally.
